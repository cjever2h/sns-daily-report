# SNS 데일리 리포트 · Threads

내 스레드 팔로워·글·반응을 매일 기록하고 분석하는 개인용 대시보드입니다.
(글식판 track 기능 대체: 메타가 Threads API 연동을 막아서, API 대신 **내 브라우저의 크롬 확장 프로그램**이 로그인된 스레드 화면을 읽어 기록합니다.)

## 구조
- `index.html`, `app.js`, `style.css`, `config.js` : 웹 대시보드 (Vercel 정적 배포)
- `extension/` : 크롬 확장 프로그램 소스 (MV3). `threads-collector.zip` 은 같은 내용의 설치용 압축 파일
- `schema.sql` : Supabase 테이블(sns_*)과 수집 함수 (`sns_ext_config`, `sns_ingest`)

## 화면
| 탭 | 내용 |
|---|---|
| 리포트 | 날짜별 리포트: 팔로워 변화, 그날 글 조회·팔로우·1만 조회당 팔로우, 베스트 글, 오늘의 행동 1개, 텍스트 복사 |
| 팔로워 | 팔로워 추이 그래프, 일·주·월 변화량 |
| 내 글 | 전체 글 검색·정렬(조회/팔로우/전환율/좋아요/답글/프로필 방문) |
| 분석 | 평균 반응, TOP 5, 시간대·요일 인사이트, 글 형식별 비교 |
| 추적 | 공개 계정 팔로워 수 매일 기록(하루/7일/30일 변화) |
| 설정 | 수집 키, 확장 프로그램 설치 안내, 수집 상태 |

## 수집 방식 (확장 프로그램)
1. 매일 정한 시각(기본 07:00, 브라우저가 꺼져 있었으면 켜진 뒤 30분 안에) 백그라운드 탭으로
   `threads.com/insights?days=7`, `?days=30`, 내 프로필, 최근 3일 글의 `insights/post/CODE`, 추적 계정 프로필을 엽니다.
2. 화면의 숫자를 읽어 수집 키와 함께 Supabase RPC `sns_ingest` 로 보냅니다.
3. 게시·수정·좋아요 같은 쓰기 동작은 하지 않습니다.

좋아요·답글·리포스트 수는 게시물 인사이트의 비율(%)에 조회수를 곱해 계산한 값이라 1~2 차이가 날 수 있습니다.
